# 🌐 Bepul Cloud Serverga (Render.com / Railway) Joylashtirish Yo'riqnomasi

Loyihangiz **Render.com** yoki **Railway.app** bepul bulutli serverlariga 1 bosishda o'rnatiladigan qilib sozlandi.

---

## ⚡ 1. Render.com ga Joylashtirish (Tavsiya etiladi - Fully Free)

1. Loyihangizni **GitHub** ga yuklang (`git push origin main`).
2. [Render.com](https://render.com) saytidan bepul ro'yxatdan o'ting.
3. Dashboard-da **New +** -> **Web Service** tugmasini bosing.
4. GitHub repozitoriyangizni ulang.
5. Render loyihadagi `render.yaml` faylini va `Procfile` ni **avtomatik aniqlaydi**.
6. **Create Web Service** tugmasini bosing.

🎉 **Natija:** 2 daqiqada saytingiz `https://royal-barber.onrender.com` kabi bepul HTTPS manzilda jonli ishlaydi!

---

## 🔍 Google Qidiruv Tizimiga Qanday Chiqadi?

Saytingiz internetga chiqqandan so'ng Google uni avtomatik indekslaydi. Jarayonni tezlashtirish uchun:

1. [Google Search Console](https://search.google.com/search-console) ga kiring.
2. Saytingiz manzilini kiriting (masalan: `https://royal-barber.onrender.com`).
3. **Sitemaps** bo'limiga o'tib, `sitemap.xml` havolasini yuboring.
4. Tayyor! Saytingiz Google qidiruvida *"Royal Barber Toshkent"*, *"Sartaroshxona bron qilish"* kabi kalit so'zlar bo'yicha indekslanadi.
